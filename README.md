# RVThereYetMenu

Трейнер для **RV There Yet?** (UE5): слоты сессии до 24, разблокировка
косметики и кассет, ремонт/посадка/лебёдка, телепорты и waypoint-ы,
встроенные dev-чит-функции игры — в одном внутриигровом меню (UE4SS, Lua).

- Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
